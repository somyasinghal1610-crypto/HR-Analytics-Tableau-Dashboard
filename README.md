# HR Analytics & Employee Attrition Dashboard | Tableau

## 📊 Project Overview

This project presents an interactive **HR Analytics Dashboard built in Tableau** to analyze employee attrition, workforce demographics, job satisfaction, and employee distribution.

The dashboard transforms HR data into meaningful visual insights that can help organizations understand workforce patterns and identify areas requiring attention.

## 🎯 Business Objectives

- Analyze overall employee attrition
- Understand workforce demographics
- Identify departments with higher attrition
- Analyze attrition across gender and age groups
- Evaluate job satisfaction across different job roles
- Understand employee distribution by education field
- Provide an interactive dashboard for HR analysis

## 📌 Key Performance Indicators

| KPI | Value |
|---|---:|
| Total Employees | 1,470 |
| Attrition Count | 237 |
| Attrition Rate | 16.12% |
| Active Employees | 1,233 |
| Average Age | 37 |

## 📈 Dashboard Features

The dashboard includes:

- Employee & Attrition KPIs
- Department-wise Attrition Analysis
- Attrition by Gender
- Employee Distribution by Age Group
- Job Satisfaction by Job Role
- Attrition by Education Field
- Attrition Rate by Gender & Age Group
- Interactive Education Filter

## 🔍 Key Insights

- The overall employee attrition rate is **16.12%**.
- **237 employees** have left the organization.
- **Sales** shows a comparatively high level of employee attrition.
- Attrition varies across different **age groups and genders**.
- Job satisfaction differs across various **job roles**.
- Education field provides another dimension for understanding employee attrition patterns.
